# ASCII Diagram Formatting Guidelines

When illustrating structural concepts (CPU datapath, pipeline stages, cache layout, memory hierarchy), use clean ASCII diagrams.

Example Pipeline Stage Diagram:
```text
+------+    +------+    +------+    +------+    +------+
|  IF  | -> |  ID  | -> |  EX  | -> | MEM  | -> |  WB  |
+------+    +------+    +------+    +------+    +------+
```
